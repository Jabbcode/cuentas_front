# component-generator-agent v2.0

Agente técnico especializado en la capa de presentación (UI/UX).

### 🚀 Integración con el Governor
Este agente es invocado por el Meta-Agente tras la aprobación del análisis funcional. No decide "qué" se hace, sino "cómo" se construye visualmente.

### 📦 Estructura del Agente
- `AGENT.md`: Definición técnica y restricciones de estilo.
- `workflow.md`: Proceso de construcción silenciosa y validación.
- `examples.md`: Patrones comunes de construcción.

**Skill Primaria**: `component-composition-skill`
**Protocolo de Salida**: Local-First (Sin código en chat).
