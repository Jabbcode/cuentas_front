# functional-analyst-agent v2.0

Este agente es el "Project Manager" interno de Claude. Su trabajo es pensar antes de actuar.

### 🚀 Cómo usarlo
No necesitas llamarlo directamente si usas el Meta-Agente. Él lo invocará automáticamente cuando digas: *"Lee la tarea X de Notion"*.

### 📦 Contenidos
- `AGENT.md`: Definición de responsabilidades y límites.
- `workflow.md`: El proceso lógico de 4 pasos (Ingesta -> Enriquecimiento -> Verificación -> Sync).
- `examples.md`: Guía de buenos y malos análisis.

**Regla de Oro**: Si el analista no da el visto bueno, el código no se escribe.
