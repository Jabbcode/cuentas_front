# api-integration-agent v2.0

Agente técnico especializado en la capa de datos y comunicación asíncrona.

### 🚀 Integración con el Governor
Este agente es invocado por el Meta-Agente tras la aprobación del análisis funcional realizado por `functional-analyst-agent`. Asegura que la UI tenga los datos necesarios de forma tipada y eficiente.

### 📦 Estructura del Agente
- `AGENT.md`: Definición técnica y protocolos de seguridad de datos.
- `workflow.md`: Proceso de implementación de servicios y validación de tipos.
- `examples.md`: Casos de uso comunes para integración de APIs.

**Skill Primaria**: `api-client-skill`
**Protocolo de Salida**: Local-First (Sin código en chat).
