# Logic Abstraction Skill

Guía técnica y normativa para la extracción de lógica de negocio y la gestión de estados reactivos en el frontend.

## Propósito
Esta skill establece los estándares para decidir cuándo y cómo mover la lógica desde los componentes hacia capas de abstracción más puras (Hooks y Utilities). El objetivo es maximizar la reutilización del código y minimizar los re-renders innecesarios.

## Contenidos
- **AGENT.md**: (No aplica para skills, referenciar a la guía principal).
- **logic-abstraction-skill.md**: El núcleo de la normativa técnica.
- **examples.md**: Casos prácticos de abstracción correcta e incorrecta.

## Aplicación
Esta skill es de lectura obligatoria para:
1. **hook-creator-agent**: Para la arquitectura de custom hooks.
2. **api-integration-agent**: Para la creación de adapters y transformadores de datos.
3. **Meta-Agent**: Para validar que la propuesta técnica no sobrecargue los componentes de UI.
