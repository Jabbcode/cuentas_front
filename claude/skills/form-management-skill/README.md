# Form Management Skill (RHF + Zod)

Manejo avanzado de formularios, validación de datos y sincronización con el estado de la UI.

## 📂 Contenido
- **SKILL.md**: Protocolos de validación, reglas de TypeScript y mejores prácticas.
- **EXAMPLES.md**: Ejemplo maestro de implementación y gestión de errores.

## 🚀 Cómo usar
Cuando necesites crear un formulario, indica a la IA:
> "Crea un formulario de [Nombre] usando la skill `@SKILL.md` y basándote en la estructura de `@EXAMPLES.md` de la carpeta `form-management-skill`."

## 🎯 Objetivos de Calidad
1. Validación 100% Type-safe.
2. Interfaz de usuario reactiva a errores en tiempo real.
3. Código limpio mediante la separación del esquema de validación y la lógica visual.
