# Data Fetching Skill (Axios + JWT)

Guía técnica para la integración con servicios backend y gestión de seguridad mediante tokens.

## 📂 Contenido
- **SKILL.md**: Especificaciones de tipado, interceptores y reglas de oro de Axios.
- **EXAMPLES.md**: Patrones de implementación de servicios, hooks y manejo de errores.

## 🚀 Cómo usar
Para que Claude aplique estos estándares, utiliza:
> "Implementa la lógica de obtención de datos para [Módulo] siguiendo la skill `@SKILL.md` de la carpeta `data-fetching-skill`."

## 🎯 Objetivos de Calidad
1. Peticiones 100% tipadas con interfaces.
2. Gestión centralizada de la autenticación mediante interceptores.
3. Manejo de errores robusto y consistente en toda la aplicación.
