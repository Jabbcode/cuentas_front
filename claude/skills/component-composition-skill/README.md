# Component Composition Skill

Guía de referencia rápida para la arquitectura de componentes React + TypeScript en este proyecto.

## 📂 Estructura de la Skill
- **SKILL.md**: Contiene las reglas técnicas, triggers de activación y estándares de tipado.
- **EXAMPLES.md**: Repositorio de patrones de diseño (Bad vs. Good) para referencia rápida.

## 🚀 Instrucciones de Uso
Para asegurar que Claude siga estos estándares, puedes usar el siguiente comando en el chat:

> "Revisa `@SKILL.md` y `@EXAMPLES.md` de la carpeta `component-composition-skill` y aplica esos patrones para crear el siguiente componente..."

## 🎯 Objetivos de Calidad
1. Reducir la deuda técnica mediante componentes desacoplados.
2. Garantizar un tipado de TypeScript robusto y extensible.
3. Fomentar la legibilidad del árbol de componentes en el JSX.
