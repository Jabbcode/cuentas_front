# Styling Skill (TailwindCSS)

Directrices para el estilizado basado en utilidades, manteniendo la consistencia visual y el rendimiento.

## 📂 Contenido
- **SKILL.md**: Reglas de orden de clases, diseño responsivo y gestión de variantes.
- **EXAMPLES.md**: Implementación de la utilidad `cn` y ejemplos de maquetación avanzada.

## 🚀 Cómo usar
Indica a la IA:
> "Estiliza este componente usando la skill `@SKILL.md` y sigue el patrón de clases dinámicas de `@EXAMPLES.md` de la carpeta `styling-skill`."

## 🎯 Objetivos de Calidad
1. Interfaz 100% responsiva y accesible.
2. Cero archivos CSS adicionales; todo el poder en el HTML/JSX.
3. Soporte nativo para Dark Mode y estados de interacción.
