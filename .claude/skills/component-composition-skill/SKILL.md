## Best Practices

1. Sigue los patrones documentados
2. Consulta `conventions.md` para convenciones

4. Maneja errores apropiadamente
5. Escribe código reutilizable

- No seguir patrones documentados
- Código hardcodeado
- Sin TypeScript types
